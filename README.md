# 录音设备指纹鉴定系统

通过录音中与说话内容无关的**设备链路特征**，判断检材是否由某部已知手机录制。
纯前端实现：特征提取基于 Web Audio API 与自研 FFT，其余全部 TypeScript，无后端依赖。

## 特征体系

| 特征 | 提取方法 | 为什么与说话内容无关 |
| --- | --- | --- |
| 频响曲线 | STFT 对数频带 60 分位能量，去全带均值 | 麦克风频响是乘性链路，归一化形状不随文本改变 |
| 本底噪声谱 | 逐频带全时段 20 分位能量，按参考电平归一化 | 语音在时频面上稀疏，低分位逼近设备本底噪声 |
| AGC 动作 | 帧 RMS 百分位分布、包络启动/恢复时间常数、顶部电平 | 反映压缩器目标电平与时间常数，属器件行为 |
| 编码器高频截止 | 噪声谱通带外推的 -3dB 残差点 + 渐近斜率平台确认 | 低通作用于全频带噪声，不依赖语音能量 |

比对时四类特征按 **频响 34% / 噪声 30% / AGC 21% / 截止 15%** 加权，
各分量先按物理尺度归一化，总距离经指数映射为 0~100 相似度。

## 页面

- **设备库页**：指纹列表与详情、JSON 导入导出、按 8 个型号模板批量生成合成设备
- **建模页**：麦克风录音（关闭浏览器 AGC/降噪）或导入参考音频 → 提取指纹 → 入库
- **检材比对页**：导入/合成检材 → 提取 → 全库逐个比对 → 相似度排名与分量明细
- **鉴定报告页**：案件列表、完整检验报告、打印/PDF、文本导出
- **指标评测页**：浏览器内运行准确率与性能评测

## 合成测试录音

链路：类语音源（共振峰合成，随机音素/基频/停顿）→ 麦克风频响 FIR →
有色本底噪声 → 帧级 AGC（软限幅）→ 多阶编码器低通 → 16bit 量化。

- 8 个型号模板，采样率覆盖 16k/24k/32k/44.1k/48k
- 同型号不同个体：各参数在模板上按高斯抖动独立实例化
- 参考录音与检材使用独立内容种子，保证"说话内容不同"

## 指标（`npm run eval` / `node scripts/eval.ts full`）

| 指标 | 目标 | 实测（主种子） |
| --- | --- | --- |
| 同型号不同个体可分率 | ≥ 80% | 97.9%（48 台，3 个附加种子 83.3%~100%） |
| 不同型号识别准确率 | ≥ 95% | 100% |
| 5 分钟检材 × 500 台指纹 | ≤ 10s | 约 7.6s（提取 ~2.1s + 比对 ~6ms，其余为检材合成） |

其他脚本：

```bash
node scripts/stability.ts   # 多种子稳定性验证
node scripts/e2e.ts         # 建库→检材→WAV 往返→比对→意见 的端到端流程
```

## 局限与说明

- 高频截止在"单阶弱滚降 + 高截止频率"或分析频带不足（如 16kHz 采样、
  截止接近奈奎斯特）时与麦克风自然滚降不可区分，系统诚实返回"未检出"，
  比对引擎按中性偏差处理而非猜测。
- 合成数据用于验证算法链路与指标；真实案件需用已知手机的参考录音建库，
  报告中的相似度是统计支持强度，最终意见须由具备资质的鉴定人复核。
